## M0 — 骨架（当前，已完成）

- 核心数据模型：UserModel（带证据画像）、HumanKnowledgeBase（精选内核 + 恢复预算硬规则）、DomainProfile、Plan；
- DomainPack 协议 + 健身参考实现（规则版，无 LLM 可跑）；
- 采集引擎：通用核心问题集（知识库派生）+ 领域补充，最小提问原则由代码强制；
- humanity/ 著作库：规范 + 19 本候选清单 + 2 本样例（《掌控习惯》《心流》）完整走通流水线，已审核（2026-09-30 批准）；
- CLI 离线演示 + 测试（守护设计原则而非只测功能）。

**验收**：`pip install -e ".[dev]"` 后 `monkeyhandler demo` 可跑通，`pytest` 全绿。✅

## M1 — 走通真实闭环（无调研）

- SQLite 存储（画像/计划/执行记录），`monkeyhandler init / plan / show` 子命令；
- LLM 接入（OpenAI 兼容）：人性知识库软上下文注入计划生成；
- 健身领域包升级：LLM 在硬规则与画像约束下生成周计划（**仅 LLM 路径**——D4 裁决后无规则回退，未配置时明确报错）。

**验收**：回答 10 个问题后得到 4 周计划，rationale 引用画像事实与人性知识条目。

## M2 — 识域上线 + 访谈升级

- web 调研 agent：逐主张交叉验证、带真实引用的 DomainProfile（替换离线占位）；
- humanity/ 流水线自动化：新著作的总结与验证由 agent 起草，**用户审核后入库**；
- 采集升级：结构化问卷 → LLM 自适应访谈（追问/澄清，按差异维度探查）。

**验收**：换一个没见过的领域（如「网球」）仍能产出合理简报、带引用的领域知识与计划骨架。

## M3 — 执行闭环与动机层 v1

- check-in（自报式生理/心理）+ 依从性追踪；
- 再校准触发器（缺席/高 RPE/平台期/历史放弃点临近）；
- 心流通道难度校准、streak、变量奖励、身份叙事；
- 行为数据反哺画像（三角验证自报偏差）。

**验收**：模拟 2 周执行数据后，计划发生可解释的调整（rationale 说明触发原因）。

## M4 — 可插拔性验证

- 第二个领域包（语言学习或编程），沉淀 **DomainPack 规范 v1** + 包质量 checklist；
- humanity/ 综合层成型：提示词库/方法论/工作流的组织与版本化；
- 英文 README / 文档站。

## M5 — 探索

- 生理数据端口升级：可穿戴设备接入（Apple Health / 华为运动健康 / Garmin）；
- 效果研究设计；社区领域包生态。
