# ADR-0002：v0.1.0 公开发布的受众与承诺边界（已批准，D15）

- **状态**：已批准（2026-10-03 创始人批复，按批复修订；回应第四轮质询 N12——「最大的决定，走了最小的流程」）
- **背景**：v0.1.0「面向使用者版本」已在 GitHub Releases 公开（exe + zip），README 下载通道改为 Releases 优先。这是一次 D1 级形态移动，但未走裁决流程——本 ADR 补记裁决。2026-10-01 送审稿（受众建议=亲友小圈子试水）经创始人批复修订生效；批复原文全文存档于 comu（场外），本 ADR 记录其产品侧生效部分。

## 创始人批复（2026-10-03，产品侧生效部分）

1. **自用不变**：创始人自用且自测试——对 D1 为**补充，非修订**，主序不变；v0.1.0 是自用产品的增量分享面，n=1 自实验继续。
2. **受众**：**有需要的人**——发布页公开可获取，作为工具分享给有需要的人（修订送审稿「亲友小圈子试水」的窄口径）。执行侧解读：被动可及 ≠ 主动推广——N7 命名裁决的挂起点（首次推广动作前）不变。
3. **承诺边界**：按送审稿三列生效（批复未提出修改），见下节。
4. **商业方向**：创始人另有保留条款（不影响 v0.1.0 承诺边界），全文存档于 comu（场外）；落地时另立裁决并重开本 ADR。

## 承诺边界（按送审稿生效）

**v0.1.0 承诺**：能运行、数据本机（可导出）、双语界面、纸笔模式零配置可用、保护规则（恢复预算/疼痛锁定）代码强制。

**v0.1.0 不承诺**：医疗效果、生成内容质量稳定性（打磨期）、跨版本数据兼容、自动更新、除 outbound-data.md 清单之外的任何外发。

危机场景专项（D11 裁决①的既定口径）：AI 陪伴模式下危机文本随对话外发（陪伴不中断优先），本地覆盖层始终提供热线与转介；**危机敏感场景推荐纸笔模式或本地模型（Ollama）**。

## 被牺牲的东西

- **SmartScreen 无签名警告**：每个新用户的第一次双击都会先看到恐吓屏（中期解法：代码签名或口碑抵消）；
- **打磨状态直接面对陌生人**：受众放宽后，生成质量与双语实例的未完成处对每位下载者同样可见——D4 收口因此更紧；
- **AI 对话的跨域稳定性**（DashScope 浏览器直连可能被拦——已知限制已标注）。
