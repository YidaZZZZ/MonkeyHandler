# ADR-0002：v0.1.0 公开发布的受众与承诺边界（送审稿——待创始人批准，D15）

- **状态**：送审（2026-10-01 起草；回应第四轮质询 N12——「最大的决定，走了最小的流程」）
- **背景**：v0.1.0「面向使用者版本」已在 GitHub Releases 公开（exe + zip），README 下载通道改为 Releases 优先。这是一次 D1 级形态移动，但未走裁决流程——本 ADR 补记裁决，供创始人批准或修订。

## 三个必答问题（执行侧建议稿）

### 1. 受众是谁

**建议裁决：亲友小圈子试水**——发布页公开可访问，但分发仅限直接链接分享；不推广、不引流、不投放到任何渠道或商店。

理由：v0.1.0 的打磨状态（生成质量、双语实例未完成）配得上小圈子反馈，配不上陌生流量；「用外部事实逼出答案」的竞品扫描也就不必启用——小圈子反馈本身就是事实。

### 2. 对 D1 是补充还是修订

**建议裁决：补充，非修订**——D1「创始人自用为主，可复用元平台次之，框架副产品」不变；v0.1.0 是自用产品的**增量试水面**（亲友可下载使用并反馈），不改变主序。

边界（写明）：不推广、不引流；出现安全事件或受众溢出（陌生下载者出现）→ 立即回本 ADR 重审。

### 3. 承诺边界

**v0.1.0 承诺**：能运行、数据本机（可导出）、双语界面、纸笔模式零配置可用、保护规则（恢复预算/疼痛锁定）代码强制。

**v0.1.0 不承诺**：医疗效果、生成内容质量稳定性（打磨期）、跨版本数据兼容、自动更新、除 outbound-data.md 清单之外的任何外发。

危机场景专项（D11 裁决①的既定口径）：AI 陪伴模式下危机文本随对话外发（陪伴不中断优先），本地覆盖层始终提供热线与转介；**危机敏感场景推荐纸笔模式或本地模型（Ollama）**。

## 被牺牲的东西

- **SmartScreen 无签名警告**：每个新用户的第一次双击都会先看到恐吓屏（中期解法：代码签名或口碑抵消）；
- **更大受众的即时可达性**（等打磨完成）；
- **AI 对话的跨域稳定性**（DashScope 浏览器直连可能被拦——已知限制已标注）。

## 验证与复审

- 小圈子反馈是 v0.1.0 的唯一效果数据（n=小样本）；
- 复审触发：安全事件、受众溢出、或创始人决定推广 → 重开本 ADR；
- 批准后：STATE.md 裁决索引收录为 D15，release notes 不变（其表述与本 ADR 一致）。
