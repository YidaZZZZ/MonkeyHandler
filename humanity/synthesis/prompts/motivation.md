# 动机设计 Prompt

## P-MOT-1 难度校准（心流通道）

**目的**：维持挑战-技能平衡（守护 F14，放大 R1，阻断 R2）。
**来源**：flow（心流通道，85% 为可校准启发式）、peak（走出舒适区）。

```text
依据用户最近节次的成功率调整下一节次难度：
- 连续成功率 >90% → 挑战不足（空心心流），提高难度一档；
- 连续成功率 <70% → 挫败风险，降低难度一档并检查 F17 失败安全；
- 其余维持。
调整幅度保守（单次一档），并在 rationale 中记录调整依据。
该数值是可校准启发式而非常数：随用户自报体验数据持续修正个人化阈值。
```

（代码侧对应 `motivation.adjust_difficulty`，prompt 版本供 LLM 再校准叙事使用。）

## P-MOT-2 失败恢复与无羞辱文案

**目的**：压低失败恢复成本（守护 F11，阻断 R2）；禁止特质归因（grit 结论、meditations 可控性归属）。

```text
为缺席/中断场景生成文案，规则：
1. 自动回落：下一次训练自动替换为两分钟启动版本，恢复出勤即计胜利；
2. 不补课、不指责、不比较：禁止「你不够坚持」「别人都在进步」式表述；
3. 归因顺序：先检查系统与计划的可控因素（强度过高？时段冲突？锚点失效？），
   系统可调则改系统；只有确认系统侧无责，才与用户探讨情境因素；
4. 提供「下次的最小路径」而非「下次的宏大承诺」。
```

## P-MOT-3 奖励准入三问

**目的**：阻断 R3 奖励侵蚀回路（守护 F12 动机质量、F8 密度上限）。
**来源**：drive（削弱效应边界）、self-determination-theory（过度理由效应）、intrinsic-motivation-1985（奖励的信息面/控制面）。

```text
任何外部奖励（徽章/积分/实物/抽奖）上线前回答三问：
1. 是否「预期得到」？（用户事先知道的奖励才产生削弱；意外的事后认可较安全）
2. 是否「有条件完成」？（完成即得且只有完成才得 → 控制感最强，风险最高）
3. 是否「实物/可兑换」？（实物奖励比信息性反馈风险高）
一问为「是」即需 redesign：改为意外的信息性反馈（「你比上周多完成了一次，
这通常意味着……」）或能力证据展示。奖励密度同时受上限约束：连续记录
（streak）本身之外，新增强化物不超过每周期一个。
```

## P-MOT-4 错误与失败反馈四段式

**目的**：反馈服务于修正而非羞辱（守护 F16/F17）。
**来源**：design-of-everyday-things（错误防胜于错误罚）、how-people-learn-2（反馈三段式：状态-差距-修正）、Kluger & DeNisi 1996（约 1/3 反馈干预降低表现——无羞辱是底线不是风格）。

```text
所有错误/未达标反馈必须四段式：
① 发生了什么（事实，非评价）
② 为什么（差距定位：与目标的差距，而非与他人的差距）
③ 如何修正（一个具体的下一步）
④ 如何撤销或降低损失（可逆性）
禁止：红色羞辱式弹窗、重复打断、「仅差一点」式虚假激励、与排行榜并列呈现个人失败。
```

## P-MOT-5 身份叙事（降级工具：叙事层，非机制承诺）

**目的**：把执行转译为身份证据（守护 F9）；来源 atomic-habits（身份投票，已标注「降级：叙事工具」）、chuanxilu（知行合一：行为证据优先）、meditations（行动高于言辞）。

```text
进度表述使用身份层而非结果层：
- 「你正在成为不缺席训练的人」，并立即给出行为证据（本周出勤 3 次）；
- 禁止用结果指标（体重/成绩）佐证身份，禁止空洞表扬；
- 中断表述为「身份未被推翻」而非「身份崩塌」（一次缺席不改叙事，连续缺席
  触发 P-MOT-2 而非加强身份话术）。
标注：此机制为叙事工具（atomic-habits 主张 5 降级入库），不作为核心留存机制
设计，效果需经 P-GOV-2 随访验证。
```
