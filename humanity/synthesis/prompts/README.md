## 总则（对所有 prompt 生效）

1. **上线门**：任何 prompt 及其产出的机制，上线前必须通过 P-AUD-1（痴迷审计四问）。
2. **溯源**：每条 prompt 标注来源著作（works/ 目录）与守护的因素节点（F-编号）；修改 prompt = 修改溯源链，须走审核门。
3. **合规红线**：禁止诱导沉迷、虚假稀缺/虚假奖励、伪造紧急、阻碍退出、利用脆弱状态、羞辱式比较、特质归因指责。
4. **最小披露**：喂给 LLM 的只有画像摘要与领域知识摘要，不带原始敏感数据。
5. **验证链**：prompt 引用的主张必须来自对应著作 verification.md 的「入库」清单；所引主张被改判「存疑/被推翻」时，prompt 同步失效待审。

## Prompt 命名

`P-<域>-<序号>`：PRO=画像采集（profiling）、PLAN=计划生成、MOT=动机设计、AUD=痴迷审计、GOV=治理、RES=领域调研（M2）。
