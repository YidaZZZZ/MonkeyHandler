## 总则（对所有 prompt 生效）

1. **唯一闸门**：一切提示词、机制与内容的去留由**用户在审核门逐案决定**（P-GOV-4）。提取与设计**不做事前伦理排除**；本库全部 prompt 均为候选提案，无强制力。
2. **溯源**：每条 prompt 标注来源著作（works/ 目录）与守护的因素节点（F-编号）；修改 prompt = 修改溯源链，须走审核门。
3. **风险信息标注**：条目应客观标注已知争议、证据边界与滥用可能——作为**信息供审核参考**，不构成排除。
4. **最小披露**：喂给 LLM 的只有画像摘要与领域知识摘要，不带原始敏感数据。
5. **验证链**：prompt 引用的主张必须来自对应著作 verification.md 的「入库」清单；所引主张被改判「存疑/被推翻」时，prompt 同步失效待审。

## Prompt 命名

`P-<域>-<序号>`：PRO=画像采集（profiling）、PLAN=计划生成、MOT=动机设计、REV=审核参考、GOV=治理、RES=领域调研（M2）。
