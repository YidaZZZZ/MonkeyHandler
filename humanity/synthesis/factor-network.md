# 影响因素网：从最终目标的反向推导

> **状态：草稿·待审核**——本文是 synthesis 层（流水线第⑥步）的初稿，经用户审核前不作为运行时依据。
> **推导目标**：让缺乏主观能动性的用户**痴迷于训练**并**掌握技能**。
> **方法**：从最终目标逐层反向分解，每层回答「上层因素的实现依赖什么」；节点标注影响方向与著作来源（book-id 对应 `works/` 目录）。

## 0. 最终目标的精确化

**最终目标 = G1 痴迷 × G2 掌握**

- **G1 痴迷**：长期、**自愿**的依从（北极星：第 8 周还在练，且是自愿的，而非被机制锁住）；
- **G2 掌握**：可验证、可迁移的技能/能力增长。

关键判断：G1 与 G2 互为因果，但也可以互相牺牲——
- 为留人而降低挑战 → 空心心流，G2 落空（R4 指标替代回路）；
- 只顾科学性而忽视动机设计 → 科学但没人练，G1 落空（R2 挫败螺旋）。

**系统的设计空间 = 两者乘积最大化**；任何以一方换另一方的机制必须被审计拦截（P-AUD-1，见 prompts/planning.md）。

目标用户画像（框架的隐含设定）：启动困难、维持困难、有历史放弃记录、自报动机偏弱。因此设计重心压在**降低启动成本、制造即时回报、结构化恢复**，而非「激励一个已经很有能动性的人」。

## 4. 网状交叉：六条关键回路

| 回路 | 类型 | 机制 | 处置 |
| --- | --- | --- | --- |
| **R1 心流飞轮** | 增强，放大 | F14 校准 → F2 体验 → F1 依从 → 练习量 → F22/F26 技能与证据 → F5 可见性 → F12 胜任 → F1 ↑ | 设计目标：让飞轮转起来 |
| **R2 挫败螺旋** | 增强，阻断 | 挑战过高 → 失败 → 挫败 → 回避 → F1 崩塌 | 断路器：F14 校准、F17 失败安全、F11 失败恢复 |
| **R3 奖励侵蚀回路** | 增强，阻断 | 外部奖励过密 → F12 内在动机被替代 → 奖励撤除后依从崩塌 | 断路器：F8 密度上限、奖励准入三问 P-MOT-3 |
| **R4 指标替代回路** | 增强，阻断 | 打卡/streak 变成目标本身 → 空心依从 → G2 落空 → 信任受损 → 流失 | 断路器：F21 逆向设计、F26 能力证据、P-GOV-1 三栏结算 |
| **R5 恢复透支回路** | 增强，阻断 | 加量 → 睡眠/压力破防 → 表现下降 → 挫败或伤病 → 退出 | 断路器：恢复预算硬规则（代码强制）、F24 减量 |
| **R6 新鲜感误判回路** | 治理 | 新机制上线 → 短期提升 → 归因错误 → 扩大 → 退潮后崩塌 | 断路器：偏差类干预强制 4-6 周随访复验 P-GOV-2 |

| 诱导沉迷 / 移除退出 | 全局 | 自愿参与检验 + 退出权四问 | P-AUD-1, F32 |
