# 君主论（The Prince / Il Principe）

- **作者/年份**：尼可罗·马基雅维利（Niccolò Machiavelli，1469-1527），约 1513 年写成，1532 年出版
- **领域**：政治哲学 / 人性论（现实主义政治传统）
- **影响力**：现代政治现实主义的开山文本之一；「马基雅维利主义」进入社会科学（人格与社会心理研究中有对应的测量维度）；其影响与所受道德批评同样巨大，是西方思想史上被讨论最多的著作之一
- **选择理由**：为「如实理解人性」提供冷峻的参照系——方案设计宁可面对人实际如何行动（健忘、趋利、以表象判断），也不建立在天真假设上；书中畏惧/爱戴的可控性结构、伪装与信义权衡等内容作为政治现实主义的方法结构一并提取，逐条交审核门决定去留
