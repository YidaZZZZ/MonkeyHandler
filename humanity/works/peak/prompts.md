# 刻意练习 —— 提取的提示词与方法论

> 流水线第④步产出。核心目标：理解人类 → 理解用户 → 让用户痴迷训练。
> **状态：全部「待审核」**——经用户审核后方可进入 synthesis/ 并被运行时消费。

## 提示词

### P1 五要素检查提示词（服务：痴迷训练）
「生成每个训练节次时强制过五要素清单：① 目标是否具体可衡量？② 哪个环节要求全神贯注？③ 反馈信号是什么、多快可得？④ 难度是否略超当前能力？⑤ 同一环节是否可重复并修正？——缺项必须在计划 rationale 中说明或补齐。」
- 出处：主张 2（刻意练习要素）
- 落点：`domains/*/plan.py` 计划生成

### P2 心理表征建设提示词（服务：痴迷训练）
「每个技能必须配备表征素材：『好动作长什么样/坏动作错在哪』的结构化对比（示范、视频、语言模型），让用户练习时脑中有对照模板，而非只有动作清单；表征素材随用户等级更新精度。」
- 出处：主张 1（心理表征）
- 落点：`domains/*/plan.py` 内容设计约束

### P3 平台期识别提示词（服务：理解用户）
「当出现『熟练但无提升』信号（完成率稳定、能力证据连续两期无增长、用户自报『就是重复』）时，判定为天真练习平台：切换手段（提高目标具体度、变换条件、升级变式）而非增加时长。」
- 出处：主张 3（自动化平台）
- 落点：M3 执行与再校准 + `core/profiling.py`

### P4 反馈可得性评估提示词（服务：理解用户）
「画像中评估用户训练场景的反馈条件：有无可量化的结果信号（重量/计时/命中率）、有无人或工具纠错（教练/录像/传感器）；反馈缺失的内容降低编排优先级或先绑定反馈手段。」
- 出处：主张 2、4（反馈与领域结构）
- 落点：`core/profiling.py` + `domains/*/plan.py`

## 方法论

### M1 练习量诚实呈现（服务：理解人类）
对外文案与进度视图禁止使用「X 小时精通」「累计打卡 N 小时 = 能力」类承诺；能力以证据（等级、动作、实测成绩）呈现，小时数最多作为投入记录而非成就度量。
- 出处：主张 5（10,000 小时澄清）+ 主张 6（解释力争议）
- 落点：`core/humanity.py` + 产品层

### M2 质量优先编排（服务：理解人类）
训练量设计以「练习质量」为第一变量：加量之前先检查五要素是否齐全；五要素缺失时加量默认无效。
- 出处：主张 6（降级口径）+ 主张 2
- 落点：`domains/*/plan.py` 计划生成

### M3 恢复预算安排（服务：理解人类）（设计建议，待审核）
任何训练计划建议包含休息与恢复的显式安排（周休、专注分段上限、睡眠建议位）；「走出舒适区」的强度设计建议受《心流》难度通道与恢复预算双重约束——恢复证据（主张 7，趋势性）与「突破极限」卖点的取舍由审核门逐案决定。
- 出处：主张 7（动机与恢复，趋势性）；难度通道互校见 flow 条目
- 落点：`domains/*/plan.py` + `core/motivation.py` + M3 执行与再校准
