# 传习录（Chuanxilu / Instructions for Practical Living）

- **作者/年份**：王阳明（王守仁，1472-1529）与弟子问答语录及论学书信，由徐爱、钱德洪等辑录；初刻于 1518 年，后多次增补
- **领域**：哲学 / 宋明理学·心学
- **影响力**：心学的核心文本，「知行合一」「致良知」成为东亚思想史的核心概念；深刻影响明清学术与日本近代人物；近年在中国教育与企业管理话语中被大量引用
- **选择理由**：与本框架高度契合——「知行合一」为「行为证据优先于口头承诺」提供哲学依据；「事上磨炼」直接支持「在真实任务中训练」的设计原则；「立志」「省察克治」对应动机承诺与复盘机制
