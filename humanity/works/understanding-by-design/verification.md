# 追求理解的教学设计 —— 逐主张验证

> 对应 summary.md 的 7 条主张。验证标准：本书是规范性设计方法论而非实证理论，按 README 的方法论类标准验证——「内部自洽 + 与学习科学证据的兼容性 + 实践采纳证据」，不适用 RCT 复现标准。
> **M0 样例注记**：本轮验证基于领域公认综述与批评的离线梳理完成；M2 起由调研 agent 复核并附真实链接。
> **审慎性说明（refer1.md）**：「须用用户真实目标而非考试逻辑」——逆向设计的阶段一必须来自用户自述目标；「它是课程设计方法，不能代替真实用户研究」。

## 入库结论

**入库（进入提示词提取）**：主张 1、2、5（设计警示）、7；主张 3、4 的方向性部分（标注为启发式）。

**存疑区（不进入提取）**：主张 3 的六侧面作为完整分类（仅作检查表）；主张 5 作为普遍规律的表述（仅作观察性警示）。

**不入库**：主张 6（WHERETO——操作工具，非主张）。

**合规约束（refer1.md）**：逆向设计不得以平台预设指标冒充用户目标（「须用用户真实目标而非考试逻辑」）；「能力证据」必须是真实可验证的表现，不得以完成度/打卡冒充迁移。
