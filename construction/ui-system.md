# 平台自身的三层推导：价值层 → 意图层 → 细节层

> **修订说明（v2）**：上一版把三层写薄了（「价值层」压缩成三句口号、意图层缺席）。本版按 refer2 的完整架构重写——**价值层**给出使命/立场/战略（合法性与边界的来源），**意图层**按五层结构+推导链把 UI 形态逐条落到「为什么」，**细节层**承载 token。
> **本文件的双重身份**：既是 UI 三层推导的阐述，也是平台自身 UI 的**意图基线**——即 CWI-1（决策盘点）的首次正式产出、CWI-5（基线冻结）的送审稿。每个决策带**反证条件**：没有反证条件的意图只是审美偏好。
> 检索来源见文末；认识状态逐条标注（强实证 / 弱实证 / 演示性应用）。

## 第一层 · 价值层（合法性来源：为什么做、为谁、什么不可让步）

### 使命与存在前提（几乎不变）

创始人自述（2026-09-29/30 对话，全文见 [being-seen.md](being-seen.md)）：一个拧巴、高敏感的抑郁症与发作性睡病患者，在生活与关系中承受大量痛苦与自我怀疑；曾渴望被某个亲近的人完全看见，最终意识到人的看见受限于有限的时间精力。**产品的存在前提：做一个有无限耐心、永不评判的陪伴者——先接住迷失的人（心理侧·被看见），再把他们一小步一小步带回世界（技能侧·训练）。** 软件的耐心无限，被完全看见的成本在架构上为零。

### 目的与价值主张（季度级）

为**低心力、高敏感人群**（含抑郁、发作性睡病等境遇；从"低心力的普通人"到"临床边缘"的谱系）服务——**不是给已经自律的人再一个效率工具**。两个引擎：觉察引擎（被看见）让 TA 重新有主体性；技能引擎（训练平台）把第一步拆到低于心力阈值。

### 立场与不可让步（年）

「训猴」讨论的和解产物（being-seen.md §五）：

- **先动，感受随后**：心力耗竭时，"礼貌地等待自驱"是失败模式——放弃假尊重（把选择压力扔回无力选择的人）；
- **不伤害底线**：不羞辱、不欺骗、可退出、危机出口（12356/急诊）——这是工程必需（该人群一次糟糕体验即灾难性流失与伤害），不是价值观装饰；
- **效果听随访数据，不听辩论**：手段无论争议与否，只分「被数据验证有效且可退出」与「没有」；
- **内核与呈现分离**（philosophy §〇）：用户界面不出现内核词汇；内核体现为体验品质。

### 战略（年）

元平台（呈现+生产）与实例（阶段性产物）；数据飞轮 = **本地迭代**（个体级回流、本地优先）；双引擎共用一个带证据的画像基座。

### 约束线（不可控，意图必须在其内成立）

单人开发节奏；纯前端 + 本机存储的隐私架构（无后端）；浏览器能力差异；WCAG 目标等级；中文/英文双语。

## 第二层 · 意图层（平台自身 UI 的意图基线）

推导链（refer2）：**事实前提 → 目标命题 → 设计原则 → 机制假设 → 形式决策 → 反证条件 → 可测推论**。以下每个决策走完整条链；原则一律引用著作库（humanity/）条目并标注置信度。

### U1 · 单列居中，而非两侧布局

- **事实前提**：用户心力有限（价值层）；主界面的第一活动是阅读与打卡；双侧栏意味着两股并行信息流。
- **目标命题**：让用户在一屏之内、无分心地处理一件事。
- **设计原则**：认知负荷与渐进披露（works/how-people-learn-2，置信度强）；心流需要无干扰的注意投注（works/flow，强）；美学可用性——整洁单列更易加工（§〇，强）。
- **机制假设**：单列 + 受控行宽 → 更少的视线跳跃与决策点 → 更低的启动成本。
- **形式决策**：居中单列容器（主平台 920px / 训练 860px），信息纵向排序，一屏一事。
- **反证条件**：用户研究出现真实的**同屏并行监控需求**（如要求同时看训练与趋势）；或测试中单列导致迷航/滚动丢失显著上升 → 引入受限的第二栏（受限=宽度和内容仍由意图层裁定）。
- **可测推论**：完成率、滚动深度、单次会话停留质量。

### U2 · 绿色系（teal），而非蓝色

- **事实前提**：价值层的"不像机构"立场；健康/正念行业的绿色语汇（Headspace/Calm 谱系）；蓝色是银行/医疗的机构色。
- **目标命题**：界面在**本能层**传达「生长与陪伴」，而非「机构与效率」。
- **设计原则**：情感化设计本能层（候选 #37 Norman——**演示性应用：该著作尚未入库**）；差异化原则。
- **机制假设**：绿 → 生长隐喻 → 对高敏感用户更低的防御唤起。
- **形式决策**：teal `#0f766e` 系（主色 + 深浅两档 + 强调色）。
- **认识状态：弱实证，诚实声明**——色彩-情绪研究的效应量小且高度语境依赖，本决策的实际依据是**语义一致性 + 行业差异化**，不属于强实证。
- **反证条件**：随访/A/B 中，蓝色（或暖米底）在信任、依从或首屏情绪自评任一指标**显著占优** → 切换 token（成本=一个文件）。
- **可测推论**：品牌自由联想测试；首屏情绪自评（SAM 或单题）。

### U3 · 首屏主导权分离（主平台=提升轨迹；产物平台=训练进程）

- **事实前提**：主平台是长期陪伴（呈现与生产），训练平台是一次目标（阶段性产物）——两者的"此刻最重要"不同。
- **设计原则**：一屏一事（V1）；progress principle（u_progress_competence，强）。
- **形式决策**：主平台首屏=跨实例提升轨迹 + 生成入口；训练平台首屏=今日训练，提升痕迹为辅助位。
- **反证条件**：训练用户调研显示打开训练平台的首要意图是"看我现在怎么样"而非"练" → 重审辅助位的位置与形态。

### U4 · 被看见空间剥离一切数字与进度

- **事实前提**：该空间的用户可能正处于自我怀疑的高唤起状态；任何比较性数字都会变成新的审判。
- **设计原则**：无评判立场（价值层）；安全先于激励（保护规则 > 心流 > 进度）。
- **形式决策**：被看见视图无统计、无连击、无进度条；只有引导、对话、卡片与危机出口。
- **反证条件**：无（这是立场性决策，由价值层直接授权；若用户本人要求加入轻量反馈，走 ADR）。

### U5 · 克制动效与声音

- **事实前提**：高敏感人群对刺激的耐受阈值差异大。
- **设计原则**：前庭安全与可关闭性（works/auditory-display 告警三关）；响应阈值（works/game-feel）。
- **形式决策**：动效 150-300ms 且尊重 reduced-motion；声音仅完成/警告两型、默认轻音量、设置可关。
- **反证条件**：随访中声音/动效投诉率或关闭率异常升高 → 重新校准默认值。

## 5. 页面意图登记表（每个界面必须回答：用户的什么问题、达成什么影响、反证条件）

> 来源：2026-10-02 创始人逐页质询——「每一页 UI 都要反思为什么这么做、希望达成什么影响、是否真的能实现」。新增/改动页面必须先在此登记再动工（N9/D12 的制度化）。

| 界面 | 用户的问题 | 存在理由 | 期望的影响 | 反证条件（何时承认失败） | 审计结论（2026-10-02） |
| --- | --- | --- | --- | --- | --- |
| 提升总览 | 「我变强了吗？」 | 首屏=提升证据（爽的第一构件：进步被看见） | 30 秒内看见变强的具体证据 | 用户持续反馈「看不出变强」→ 重设计证据形态 | **部分不达标**：统计是活动记账（完成/连击），「变强」证据只有 RPE 趋势一句——能力证据（L0 出勤即证据、能力测评）形态缺失，随 M1 补 |
| 我的训练平台 | 「我现在做什么 / 还能开什么新方向」 | 行动入口 + 增量方向 | 表单即行动，无解释负担 | 表单让用户犹豫超 30 秒 → 再砍字段 | ✅ 本轮已修：砍掉两段平台自述残留 |
| 被看见 | 「此刻我心里堵得慌」 | 接住；不评判 | 写下第一句的门槛趋近于零；危机时热线一步可达 | 引导问题像作业 → 减步；AI 对话被跨域拦截的频率过高 → 本地代理提级 | ✅ 基本达标；AI 对话的跨域拦截为已知限制（如实标注） |
| 训练实例·今日训练 | 「我现在做什么」 | 训练进程主导（D 裁决：产物平台训练主导） | 打卡三步内完成 | 打卡超过三步 → 再砍 | ✅ |
| 训练实例·关于计划 | 「这个计划凭什么这么安排」 | 用户主动点开的「为什么」（可解释性） | 读完知道每部分的依据与边界 | 用户反馈读完更焦虑 → 重写 | ✅ 用户语言，无内核词 |

**登记纪律**：新增任何界面/页面前，先在本表登记四栏（用户问题/存在理由/期望影响/反证条件），缺「反证条件」不得动工——这是 philosophy §〇 与 N9 的制度化执行点。
