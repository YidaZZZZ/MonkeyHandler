# 意图层：元素框架

> 回答「为什么是这个样子」。规格是**判决性**的（必须如何），意图是**解释性**的（为何如此、凭什么判断它是好的、什么条件下该放弃）。
> 元素框架来自 `humanity/refer/refer2.md`；平台适配示例为本仓库现状（M0）。**状态：草稿·待审核。**

## 一、意图五层结构（自下而上，每层为下层提供理由）

### 第 1 层 · 存在性理由（Why this at all）
解决谁的什么真实问题？证据是什么？不做损失什么，做了引入什么代价？
- 平台示例：「训练面板的节次级 rationale 为什么存在——M0 的计划级 rationale 只回答『为什么这样排』，用户执行单次训练时看不到『为什么练这个』（证据：M0 demo 输出结构）。」

### 第 2 层 · 价值与权衡（What trade-off）
同时被服务的是谁？冲突时按什么**排序规则**取舍？
- 平台排序规则草案（待审核）：`G1 长期依从 > G2 掌握真实性 > 操作效率 > 视觉简洁`；恢复预算（已批准硬规则）优先于训练连续性。
- ADR 必须写「**被牺牲的东西**」——否则等于没权衡。

### 第 3 层 · 设计原则（By what rule）
从著作库挑出与当前场景匹配的规则作为裁判依据（每条挂 works 条目与证据等级），而非审美口癖。本平台当前原则清单见 [methodology-map.md](methodology-map.md) 第 3 层。

### 第 4 层 · 设计模式与证据（What pattern, with what evidence）
反复出现的「问题—情境—解法」三元组，每个模式标**置信度**（对应著作 verification 的证据分级 strong/moderate/anecdotal）。
- 高置信模式示例：「两分钟启动」（atomic-habits + 行为激活证据）；「间隔检索」（make-it-stick，元分析级）。
- 低置信模式示例：「兴趣曲线」（the-art-of-game-design，对照实证缺失）——可作为假设提出，不得作为硬依据。

### 第 5 层 · 形式映射（How principle becomes form）
把原则落成**可观察的形式变量**，必须写中间变量，否则无法验证。
- 示例：「维持心流通道」（原则）→ 中间变量：节次成功率、自报 RPE → 形式变量：难度档位（`motivation.adjust_difficulty`）、钩子类型选型。

## 二、推导链（单个表现形式的成立条件，缺一不可）

> 事实前提 → 目标命题 → 设计原则 → 机制假设 → 形式决策 → **反证条件** → 可测推论

没有反证条件的意图不是意图，只是事后包装。这与著作库的纪律同构：verification 判「被推翻」时引用它的条目同步失效。

## 三、意图之间的三类关系

- **协作**：一个决策同时支撑多个意图（高质量方案的特征）——如「完成即记录」同时支撑 F8 即时回报、F5 进度可见、F26 能力证据。
- **张力**：冲突解法不是折中而是**分层**。平台已知张力清单：
  1. F8 即时回报密度 vs R3 奖励侵蚀（self-determination-theory）→ 分层：信息性反馈为默认层，外部奖励为可选层（逐项审核启用）；
  2. G2 掌握（难度诚实）vs G1 留存（挫败回避）→ 分层：默认难度 ≈85% 成功率，失败自动回落两分钟版本；
  3. 操作效率 vs 中断安全 → 分层：默认路径最短、恢复预算破防时自动设闸（降强度）。
- **涌现**：一个细节别扭，往往是它上一级意图与其他路径的意图不一致——改细节没用，要改那层规则。

## 四、意图分层治理（意图只挂在它需要的最小层级上）

| 层级 | 本平台示例 | 变更频率 |
| --- | --- | --- |
| 战略意图 | **产品理念：让提升本身成为强化物**（对自我提升上瘾，见 [../philosophy.md](../philosophy.md)）；北极星 = 第 8 周还在练的比例；G1×G2 乘积最大化 | 年 |
| 领域意图 | 恢复预算硬规则；依从性优先于强度递进 | 季度 |
| 流程意图 | 计划生成走逆向设计顺序；W2→W4 的 open_questions 回流 | 版本 |
| 界面意图 | 某屏唯一主操作（如 check-in 屏：提交即完成，不做二次推销） | 迭代 |
| 元素意图 | 某按钮为何是主要动作、为何禁用 | 天 |

## 五、三张表（意图层的交付物 = 冻结基线）

1. **意图登记表**：ID（INT-xx）｜归属层级｜提出者｜证据来源（可指 works 条目/访谈/数据）｜置信度｜适用条件｜**反证条件**｜复审触发条件｜到期复审日。
2. **决策记录（ADR）**：决策背景 → 候选方案与各自代价 → 最终选择 → **被牺牲的东西** → 验证指标 → 复审触发条件。
3. **意图追溯矩阵**：意图 ID → 原则 → 模式 → 规格条目（detail 层的 S/R/C/ST/E/F 编号）→ 验收指标，双向可达。

基线冻结后，任何意图变更走 ADR 并更新追溯矩阵（对 detail 层的影响同步标出）。
