# 被看见（Being seen）—— 主平台常驻功能 · 内核设计说明

> **定位**：主平台下的**常驻功能**（心理侧/被看见侧），与技能训练侧（训练平台）并立。面向**低心力、高敏感人群**（含抑郁、发作性睡病等境遇）。
> **初衷**（2026-09-29/30 与创始人对话确立）：人对人的倾诉是「被看见的渴望」，但受限于人有限的时间精力，只能饮鸩止渴。本功能的**第一性原理**：软件的耐心是无限的——被完全看见的成本，在架构上为零。

## 〇、方法论并入（D2：guanzi「见」已并入觉察引擎）

guanzi 的 `SEEME_SYSTEM`（罐子的灵魂）核心规则已并入本功能的 SEE_PROMPT v2：

| guanzi 规则 | 并入后的落点 |
| --- | --- |
| 以分享引出，不以提问索取；数问号硬规则（>1 删到 1） | SEE_PROMPT 第一原则 |
| 梳理节奏：三四轮后收拢交还校验，错了也没关系 | 节奏段 |
| 模式标定：「我一般是……但……」是全场最重要的时刻 | 节奏段第 5 条 |
| 身体线索是感受的坐标；比方复述比方，不复述结论 | 节奏段 |
| 抵触是最珍贵的时刻：停下、承认、不讨好 | 抵触段 |
| 禁止清单：不说教/不灌鸡汤/不给行动建议（除非要）/不套话/不心理学术语/≤150 字 | 禁止段 |

待平移（M1+）：`CRYSTALLIZE_SYSTEM` 的**本心卡片叙事模板**（触发情境→起初的念头→剥离妄念→浮现的本心→一句话指引）——AI 结晶模式将采用此模板生成卡片，与现有速记卡（感受/发现/一小步）并存；「格」（费曼打磨，费曼卡片）归**技能引擎**，作为能力证据的叙事化加工方法（讲给小白听→挑刺→修正）。

产品站**亚临床低心力谱系**；临床信号（危机词、持续症状）→ 一律**转介不处理**（危机协议不变）；为临床人群保留「通用练习 + 礼仪性转介」的礼仪。产品不进临床。

## 一、两个引擎，一个基座

- **技能引擎**（训练平台，已具雏形）：把第一步拆到低于心力阈值，先动起来，感受随后；
- **觉察引擎**（本功能，参考 guanzi「见」的理念）：无评判的倾诉与梳理，找回安全的自我与主体性；
- **共同基座**：带证据的画像、本机数据（本地迭代）、效果随访。两个引擎互为桥梁——本心卡片的一小步通向训练平台，训练的完成感回到被看见的足迹。

## 二、觉察五步法（参考 guanzi「见」：倾听→澄清→镜映→辨析→结晶）

1. **倾听**：完整接住，不急着回应；
2. **澄清**：最多一个简短问题，邀请多说一点；
3. **镜映**：复述听到的感受（不是共情表演——AI 不说"我完全理解你"，因为它做不到，假装反而是伤害）；
4. **辨析**：用户在「墙」（自我保护的想法）与「本心」之间挣扎时，**不宣判**——平台不做判官（判错的代价由最脆弱的人承担）；代之以**成本极小的现实检验**（行为实验）："担心出门会崩溃？试试十分钟版本，让现实回答。"有效、尊重、可测量；
5. **结晶**：自然告一段落时，收束成**本心卡片**（此刻最真实的感受 + 一个发现 + 可选的一小步）。

## 三、双模式

| 模式 | 条件 | 形态 |
| --- | --- | --- |
| **陪伴对话** | 设置里已连接 AI 服务（多模型，OpenAI 兼容） | 五步法驱动 AI 对话（system prompt 见 demo 源码 SEE_PROMPT，铁律：60-120 字、不诊断、不催促、不表演共情、如实承认是 AI） |
| **纸笔模式** | 未连接 AI（默认） | 五步引导卡 + 自书写——写给自己的话同样被看见；不因没有 Key 而失去本功能 |

## 四、危机协议（本功能的承重墙，非价值观装饰）

对这一人群，一次糟糕的体验 = 灾难性伤害与流失；危机响应因此是**工程必需**：

1. **关键词识别**（本地、即时）：自伤/自杀类表述触发温和覆盖层（不评判、不惊吓）；
2. **资源**：心理援助热线 12356（中国，24 小时）/ 当地急诊 / 告诉身边一个人；
3. **AI 层铁律**（写入 SEE_PROMPT）：识别到危机立即停止引导，转专业帮助，之后保持极简短陪伴；
4. **边界声明**：本功能不诊断、不替代治疗；专向心理治疗（如针对抑郁的 CBT）属于专业领域——与识域原则一致（大模型常识 + 专业调研）。

## 五、与「训猴」讨论的和解（创始人 2026-09-29/30 表述的产品哲学）

- 心力耗竭时，「礼貌地等待用户自驱」是失败模式——**先动，感受随后**（行为激活），这是训猴表述的有效内核；
- 该内核不需要以羞辱、欺骗、施压为捷径：**平台的无限耐心消灭了粗暴存在的理由**（训猴师的粗暴来自时间有限与无法沟通，本架构两者皆无）；
- 需要放弃的是假尊重（把选择压力扔回无力选择的人），需要保留的是底线（不伤害、可退出、危机出口）；
- 手段是否有效不听辩论，听随访数据（P-GOV-2 纪律）。**诚实声明：当前为 n=1 自实验（创始人为唯一用户），随访体系自 M3 起建立——在此之前一切效果陈述均为自报观察。**
## 六、效果定义（创始人授权由本仓库拟定训练阶梯）

技能侧对这个人群的**第一块能力证据**，不是"掌握新技能"，而是：

> **L0 连续 3 天，每天完成两分钟启动版**（出现于房间之外的动作亦可）→ L1 一周内 3 次完整轻量训练 → L2 一个 20 天周期完成率 ≥60% 且疼痛/缺席反指标稳定 → L3 能力证据（体态/力量/自主练习）→ …

每一级都低到「心力最差的一天也够得着」；阶梯本身由随访数据修订（认领自创始人，2026-09-30）。
