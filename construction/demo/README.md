# demo —— 两份呈现（主平台 + 训练平台）

> **主平台（`main.html`）更为重要**：呈现与生产——提升总览（跨实例、数据飞轮）、我的训练平台（产物列表与生成管线）、平台的成长。运行方式：浏览器直接打开。
> **训练平台（`index.html`）**：阶段性产物的实例样例——针对「20 天缓解脊柱侧弯」生成的专项训练界面，训练进程主导（提升痕迹为辅助位）。
> 两页共享同一 origin 的 localStorage（本地迭代：数据不出本机）；页头可互相跳转。

## 主平台演示什么（对应 construction/philosophy.md §三 主平台要求）

| 视图 | 内容 |
| --- | --- |
| 提升总览 | 大数字统计（完成/连击/疼痛/缺席）+ RPE 轨迹 SVG 图 + 解读句——**提升主导**；训练进程不在此占主导 |
| 我的训练平台 | 产物卡片（20 天脊柱侧弯，进度条）+ 生成管线四步（需求与画像 → 意图层 → 细节层 → demo 交付） |
| 平台的成长 | 知识资产（著作/提取/内核/硬规则）+ 数据飞轮（实例→数据→修正→更准的下一期）+ 构筑体系 |

## 视觉方法论的来源说明（诚实溯源）

主平台的视觉手法（大数字对比、轨迹图叙事、卡片亲密性与对齐、本能层观感）目前是**演示性应用**——对应的方法论著作已列入 humanity/ 候选清单 #37-44「呈现与视觉影响力」（情感化设计、写给大家看的设计书、设计的法则、点石成金、栅格系统、用数据讲故事、设计中的设计、上瘾），**尚未走完流水线**；入库后这些手法将从"演示性应用"升级为"有出处的已入库方法论"。

## 训练平台演示什么

| 构筑对象 | 在 demo 中的体现 |
| --- | --- |
| **profiling（个性化了解）** | 7 题结构化问卷（每题带 decision_point 注解）；答案实时改变计划——时间预算 tier 裁剪、睡眠/压力触发**恢复预算硬规则**、疼痛史决定安全横幅、动机取向决定激励文案 |
| **意图层** | 「为什么」页公开意图基线：排序规则、硬规则、原则清单（挂 works 出处）；每个练习「为什么练」可展开 |
| **细节层** | 键盘全可达、aria-live 反馈、缺席回落（两分钟版）、reduced-motion 尊重 |
| **价值观层** | 不构筑——安全声明以「约束线」身份出现（非医疗建议、专业评估提示） |

## 安全与常识边界

1. 训练平台**不是医疗处方**；脊柱侧弯专向训练（如施罗斯疗法）需要专业评估与认证指导，未评估用户持续看到提示。
2. 练习内容为通用对称性运动与拉伸常识（识域不设构筑策略：大模型常识 + 专业调研）。
3. check-in 疼痛 ≥4 触发降级 + 就医建议横幅，并锁定递进。
