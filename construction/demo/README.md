# demo —— 初版交互 UI（20 天脊柱侧弯运动与拉伸）

> **定位**：本 demo 是一个**阶段性产物**的实例样例——由元平台（MonkeyHandler）针对「20 天从运动和拉伸层面缓解脊柱侧弯」这一具体需求生成；它不是平台本体。实例运行中产生的用户数据将回流元平台（数据飞轮，见 docs/architecture.md §1.1）。
> **CWD-7 的初版纵向切片**：完整细节层规格尚未撰写，本 demo 先行打穿「个性化了解 → 意图 → 交互」的传递链。
> **运行方式**：浏览器直接打开 `index.html`（无需服务器，数据仅存本机 localStorage，不上传）。

## 它演示什么

| 构筑对象 | 在 demo 中的体现 |
| --- | --- |
| **profiling（个性化了解）** | 首次进入的 7 题结构化问卷（含 decision_point 注解）；答案实时改变计划——时间预算裁剪内容、睡眠/压力触发**恢复预算硬规则**、疼痛史决定安全横幅、动机取向决定激励文案 |
| **意图层** | 「为什么」页公开演示用的意图基线：排序规则（安全 > 依从 > 掌握 > 效率 > 美观）、硬规则、原则清单（挂 works 出处）；每个练习的「为什么练」一句话 rationale 可展开 |
| **细节层** | 键盘全可达（语义按钮 + focus 样式）、aria-live 反馈、状态反馈即时（100ms 目标）、缺席回落（两分钟版）、reduced-motion 尊重 |
| **价值观层** | 不构筑——但安全声明以「约束线」身份出现（非医疗建议、专业评估提示），不属于价值观层内容 |

## 安全与常识边界（显式声明）

1. 本 demo **不是医疗处方**。脊柱侧弯的专向训练（如施罗斯疗法）需要专业评估与认证治疗师指导；未评估用户会看到持续提示。
2. 练习内容为**通用的对称性运动与拉伸常识**（呼吸、活动度、核心稳定、姿势觉察）——按 2026-09-29 决定，识域暂不设构筑策略，专业方法由后续大模型调研产生；每个练习的 rationale 均标注「通用常识」。
3. 疼痛 check-in ≥4 触发降级 + 就医建议横幅，并锁定递进（recovery_budget 同款硬规则逻辑）。
